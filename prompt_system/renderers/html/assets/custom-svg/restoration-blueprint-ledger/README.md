# Restoration custom SVG system

這三個 SVG 是為 `restoration-blueprint-ledger` 原創的 Theme 資產，不是點陣圖描圖，也不依賴外部網址。

- `restoration-heritage-block.svg`：封面老屋群像。
- `restoration-perimeter.svg`：屋簷、拱窗、磚牆植栽與木作工具四角構圖。
- `restoration-tools-study.svg`：結尾頁修復工具靜物。

設計規格：

- 透明背景。
- 共用 `#17384F`、`#345F73`、`#A44C32`、`#C6A264` 與紙張中性色。
- 主輪廓 8px、次輪廓 5px、細節線 3.5–4px。
- 不含文字，避免 SVG 內字型依賴。
- 可直接內嵌為 standalone data URI。
