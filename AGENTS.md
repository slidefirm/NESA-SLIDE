# NESA-SLIDE contributor boundary

This release is a portable Codex Desktop / Windows package. Keep all generated working output in `workspace/` and keep source folders immutable during a normal deck run.

Use the seven repository-local Skills for their matching renderer workflows. Image2 uses seven-section assembled YAML; HTML and PPTX use their own renderer adapters and content manifests. Do not flatten editable HTML or PPTX output into a full-slide screenshot.

Before modifying canonical source, inspect Git state and preserve unrelated work. Do not publish, deploy, push, create a PR or modify a remote service without explicit authorization.
