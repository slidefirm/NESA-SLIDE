# Security Policy

Do not file public issues containing credentials, customer data, employee data, private presentation content, or confidential reproduction details.

Report potential vulnerabilities privately to the Slide Firm maintainers with the affected version, impact, reproduction steps, and a safe mitigation when available. Never include API keys or access tokens.

NESA-SLIDE v0.2.0 is designed for local Windows and Codex Desktop workflows. GitHub Pages hosts only the static public DEMO and does not provide server-side save APIs.
