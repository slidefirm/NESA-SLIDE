# 簡報分類與章節結構參考

在內容規劃階段，根據簡報主題、受眾與目標選擇主要類型。章節是起點，不是固定模板；可依時間與任務刪減、合併或混合。

## 學術交流型

適用於研討會、論文發表、學術成果報告與研究所報告。

1. 研究動機與問題定義
2. 文獻回顧與理論基礎
3. 研究設計：樣本、工具與流程
4. 研究結果：統計、圖表與顯著性
5. 討論：解釋、限制與未來研究
6. 結論與貢獻

## 進度匯報型

適用於週會、月會、專案更新、KPI 報告與 OKR 檢視。

1. 摘要與 Key Takeaways
2. 目標與衡量指標
3. 進度狀態與里程碑
4. 數據趨勢與分布
5. 問題、風險與對策
6. 下一步行動與資源需求

## 行銷提案型

適用於客戶提案、新產品發表、合作洽談與廣告企劃。

1. 問題洞察或市場痛點
2. 目標受眾與需求分段
3. 解決方案、流程 Demo 與價值主張
4. 競爭分析與差異化優勢
5. 案例、ROI 或客戶見證
6. 商業模型、價格、時程與支援資源
7. Call to Action

## 教學演講型

適用於對外演講、企業培訓、工作坊、TED 風格分享與課程教學。

1. 引起動機：情境、挑戰或提問
2. 學習目標與課程地圖
3. 概念講解與可視化模型
4. 示範或案例解析
5. 互動活動、練習與即時回饋
6. 結論回顧與工具資源

## 創業募資型

適用於投資人 Pitch、Demo Day 與加速器評審。

1. 使命願景
2. 市場痛點與規模
3. 解決方案與產品 Demo
4. 商業模式與收益預測
5. 競爭優勢與護城河
6. Traction 與指標
7. Team 與顧問
8. 融資需求與用途

## 選型原則

- 跨兩種類型時以主要目的為準，再借用另一類型的一至兩個必要章節。
- 向主管報告研究成果仍可採學術交流型，但應縮短文獻回顧並提前結論。
- 向客戶介紹新功能通常採行銷提案型，結尾應有可執行的下一步。
- 公司內部分享技術知識通常採教學演講型，但可加入進度匯報型的風險與行動頁。
- 不要因選了類型就強制使用固定頁數、固定 Layout sequence 或固定內容格式。
