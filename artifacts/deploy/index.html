Layout Gallery
依封面、目錄、內容、圖表、資訊圖像與特定版面分類，直接從頁面用途找到合適 Layout。
Layout 卡片只保留圖片案例與 YAML 結構，不連到 HTML 或 PPTX；各 renderer 的成品走獨立賽道。
新增 Layout・相對位置候選
這一區把「1 + N」拆成可比較的空間關係，不再只用卡片數量命名。先看標題／主區在哪裡，再看 N 個內容模組如何排列。
目前是 Review Candidate：有實際百分比區域與 YAML，但尚未加入正式 Layout core，也還沒有生成 Image2、HTML 或 PPTX adapter。六款各自使用不同內容案例、字稿、數據與視覺方向。
封面 Layout 提案
整合另一個任務的 10 種封面構圖研究與生成預覽；每款使用不同內容情境、字稿、配色、材質與主視覺語彙。
這些也維持候選狀態；不會因為出現在同一頁就自動併入正式封面 Layout。10 款的文字正確性與差異性皆通過；安全區為 5 款通過、5 款需人工確認，卡片已逐張標示。
Theme 視覺主題
Theme 是一套可重複套用的視覺規則：定義背景質地、色盤、字體與裝飾語彙， 再和不同 Layout 組合。這裡選的是設計語言，不是一份已經寫完的簡報。
想先決定整份簡報「長什麼樣」，從 Theme 開始；內容頁的結構仍由 Layout 決定。
HTML Preset 完整簡報
Preset 是已驗收的 HTML 視覺案例索引；這裡只比較 Theme DNA 與案例畫面， 不從 Layout Catalog 直接開啟 renderer 成品。
HTML 的編輯、下載與執行環境維持獨立賽道；Preset 不會混進通用 Layout 分類。

圖片預覽

正式 Image2 生圖必須回到目前工作的 Codex，使用完整七段式 YAML 與內建 image_gen；網站本身不會啟動另一個 Codex 或直接發布。

本機 server 只供預覽，不執行生圖或部署。
