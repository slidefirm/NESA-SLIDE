# Changelog

## 0.1.0

- Initial public NESA-SLIDE packaging for Codex Desktop on Windows.
- Seven local presentation production Skills with shared Theme/Layout adapters.
- Source and portable release profiles with deterministic inventory and dependency-closure reports.
- Runtime capability contract for built-in image generation, browser QA, Node/Python and PowerPoint.
- Four fully fictional Traditional-Chinese Showcase decks are distributed separately from the portable runtime package.

### Known boundary

v0.1.0 does not claim manual visual acceptance for every 36 Theme × 75 Layout combination. Per-artifact renderer QA evidence is required before a deck is called complete.
