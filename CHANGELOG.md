# Changelog

## 0.2.1 — 2026-09-01

- Clone-native Codex and Claude Code workspace with checked-in Skill discovery for both agents.
- One `create-presentation` front door that routes planning, design, HTML, PPTX, and Image2 work.
- Cross-platform `setup`, `doctor`, `dev`, `demo`, and Skill-parity commands.
- README rewritten around a paste-the-link-to-your-agent workflow; portable ZIP is now secondary.

## 0.2.0 — 2026-09-01

- Public HTML DEMO and GitHub Pages delivery.
- Portable Windows package with recipient-side integrity and capability checks.
- 36 Themes, 75 Layouts, 43 style cases, 333 renderer adapters, and a 36×75 registry.
- Seven repository-local presentation Skills with `.agents/skills` as the canonical source.
- Deterministic ZIP generation and release builds that refuse dirty Git worktrees.
- Bilingual public documentation and unified Slide Firm licensing.

### Validation boundary

The release validates the packaged core, adapters, registry, integrity ledger, and the bundled HTML DEMO. It does not claim complete visual acceptance of every HTML/PPTX combination, Image2 provider output, macOS, or native PowerPoint rendering.

## 0.1.0 — 2026-08-28

- Initial public NESA-SLIDE packaging for Codex Desktop on Windows.
- Seven local presentation-production Skills with shared Theme/Layout adapters.
